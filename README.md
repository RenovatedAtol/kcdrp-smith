# Ремёсла → торговый груз (KCD Roleplay)

Калькулятор для сервера KCD Roleplay [RU]: себестоимость каждого ремесленного предмета, сколько он засчитывается в торговый груз своего ремесла и сколько вы теряете, если добивать груз самым выгодным товаром.

**Сайт:** https://renovatedatol.github.io/kcdrp-smith/

## Что умеет

- Все девять ремёсел сервера — кузнечное, бронное, портняжное, лучное, ювелирное дело, алхимия, кулинария, пивоварение, плотницкое дело — выбор в заголовке. У каждого свой груз: стоимость, принимаемые товары, свежесть, склад города.
- Рецепты 2–10 уровней (1-й не показывается — качается быстро; уровни, где ни один предмет не помещается в груз, тоже): материалы, плата станка, выход.
- Себестоимость по ценам аукциона (средняя или минимальная); полуфабрикаты — изготовить самому или купить, что дешевле; из нескольких рецептов одного материала берётся самый дешёвый.
- Сколько предмет засчитывается в груз, КПД, потеря за штуку и на целый груз с добивкой (авто — самый выгодный товар груза, которого на рынке хватает на целый груз); предметы дороже груза помечены — их излишек сгорает.
- «Продать груз от»: все затраты (материалы, платы станков, добивка, упаковка 10 гр.) и примерно сколько км везти при обычном спросе (25 гр./км, до 150).
- Лучший предмет на каждом уровне.
- Корзина: «+» у предмета добавляет его на один груз; что сделать по пути, что взять с собой (добивка отдельно), раскладка по грузам (каждый предмет — в груз своего ремесла), затраты и потеря; список копируется в буфер.
- Вкладки: «Корзина и предметы», «Материалы и цены» (свои цены, способ, исключение материалов), «Куда везти» (склады городов, расстояния, нужда, прибыль с дороги, 3 лучших маршрута).
- Окно «Цены рынка»: рыночные цены, аукцион (средняя, минимальная), цена в грузе, выставлено и продано.

## Откуда данные

- Рецепты — [вики сервера](https://wiki.kcdroleplay.com/recipes/), собираются скриптом `tools/build_crafts.py` в `data/crafts.json`. Состав и стоимость грузов — по вики; груза портного в вики нет — по окну упаковки в игре; груза лучника нет нигде — предположение (помечено на сайте).
- Цены — публичный [API сервера](https://account.kcdroleplay.com/api/ucp/realm?world=ru). Сервер не даёт браузеру читать его с других сайтов (CORS), поэтому GitHub Action `.github/workflows/prices.yml` каждые 30 минут копирует цены в ветку `prices` (`prices.json`), а страница читает её. Если наша копия старше 1,5 часа (расписание GitHub бывает ненадёжным), цены аукциона берутся из ежечасной копии [калькулятора DanekKuznec](https://danekkuznec.github.io/kcd2-rp-crafting/), если она свежее; склады городов и рыночные цены — из нашей.
- Цена товара в грузе — поле `instant` аукциона (совпадает с окном упаковки в игре); где его нет — значения из окна упаковки или рыночная цена сервера.
- Русские названия и иконки предметов — из данных калькулятора DanekKuznec (`data.js`, `ricon.js`); иконки — игровая графика Kingdom Come: Deliverance II (© Warhorse Studios), лежат в `data/icons/`.

## Обновить рецепты

```sh
curl -sL https://wiki.kcdroleplay.com/recipes/ -o /tmp/recipes.html
curl -sL "https://account.kcdroleplay.com/api/ucp/realm?world=ru" -o /tmp/realm.json
curl -sL https://danekkuznec.github.io/kcd2-rp-crafting/data.js -o /tmp/danek.js
curl -sL https://danekkuznec.github.io/kcd2-rp-crafting/ricon.js -o /tmp/ricon.js
python3 -I tools/build_crafts.py /tmp/recipes.html /tmp/realm.json /tmp/danek.js /tmp/ricon.js --icons data/icons > data/crafts.json
```

Цены вручную: вкладка **Actions → prices → Run workflow**.
